# 协作架构

Skill 管跨项目规范；团队 Project 管项目事实和角色；STATUS 管进展摘要；任务主记录管任务责任和证据；本机 ME.md 管个人身份。

Google Drive 是共享主存储。云端使用 Docs / Sheets / Slides，本机可以保留 Markdown 缓存与草稿。稳定 file ID 定位主记录，原生项目索引供人和 agent 导航；每次编辑不需要重写索引。迁移格式导致 ID 变化时更新相关链接，验证后归档旧版。

初始化由 PM 或授权负责人执行，日常 work 不重建项目。读取当前版本后进行授权的最小修改，完成后回读。任务完成、发布成功、客户验收是不同状态。

Docs 局部修改应使用 revision 控制；Sheets 使用已指定的串行维护者，不能把先读后写当作原子锁。本地脚本只生成草稿，不实现云端并发协调。

宿主 Google 集成是接入入口；读取能力、写入能力与账号均按当前工具核验。安装 skill 不会自动唤醒其他 agent；下一次 work 检查变化，后台订阅仍是后续工作。
