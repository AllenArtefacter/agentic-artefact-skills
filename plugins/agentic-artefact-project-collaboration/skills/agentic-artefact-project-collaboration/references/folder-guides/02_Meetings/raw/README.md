# Meeting raw sources

Preserve original transcript, recording and supplied attachments. Reuse matching source IDs rather than uploading duplicates. Record known meeting date, source and version; do not infer attendees from a roster. Correct transcription interpretations in the note, not by silently rewriting the raw source. Link each source from its note and brief. For replacements, preserve original evidence and explain source discrepancies. Follow [meeting-notes.md](../../../meeting-notes.md).
