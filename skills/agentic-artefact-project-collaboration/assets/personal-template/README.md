# 线上个人项目空间

项目：{{PROJECT_NAME}} · 团队入口：{{PROJECT_FOLDER}}

放在自己的 My Drive 中独立的项目目录，不是团队 Shared Drive 下名为“个人”的文件夹。实际隐私由 Google ACL 决定。

- Inbox：待整理、尚未决定是否纳入项目的个人资料。
- Drafts：个人研究、思考与工作草稿。
- To_Publish：拟发布给团队的内容及目标 TASK / DEL / MAT-ID。

团队已有资料用链接引用，不克隆一整套 Timeline 和 Plan。发布时选择明确内容，登记目标团队位置及 source ID；发布后团队文件是共享工作依据。个人文件可保留为个人历史，不再与团队文件双向自动覆盖。

个人目录 ID 只在本人本地连接配置保存，不写团队 manifest。个人目录仅通过已授权的宿主集成访问，不自动扫描。

## Agent 必读入口

每次先读个人 `ME.md`，再读团队 `Project.md` 和 `STATUS.md`。ME.md 填本人姓名、邮箱、person_id 和职责；当前任务从团队主表查询，不维护另一份任务真相。
