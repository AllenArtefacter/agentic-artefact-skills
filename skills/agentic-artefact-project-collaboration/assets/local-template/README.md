# {{PROJECT_NAME}} · 本地个人工作空间

这里的所有内容都是本人线下空间。即使文件来自团队，它在这里也只是个人缓存或工作副本；不会因为保存到本机而对其他人可见。

- context：agent 按需维护的项目清单、未处理变化及本人读取缓存；不直接编辑缓存作为团队改动。
- working：个人分析、代码、实验、草稿。
- outbox：等待明确发布的内容与状态变更提案。
- .collab：本机连接配置、扫描状态和已读记录；不上传、不提交 Git。

发布过程：本地草稿 → 选定团队目标和记录 ID → 查看最新团队版本 → 明确上传或编辑 → 回读验证 → 更新 Timeline 与目录索引状态/证据。outbox 不自动发布。

本地目录不是云盘镜像。团队文档修改不会自动覆盖 working；个人改动也不会自动回传。下载过的文件可离线查看，但不能声称它仍是最新或仍具有线上访问权限。agent 读取线上文件时需验证项目归属。

## Agent 必读入口

每次先读个人 `ME.md`，再读团队 `Project.md` 和 `STATUS.md`。ME.md 填本人姓名、邮箱、person_id 和职责；当前任务从团队主表查询，不维护另一份任务真相。
