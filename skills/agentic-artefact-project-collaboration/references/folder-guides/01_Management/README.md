# Management

Keep one native Project Timeline Sheet with Timeline and Backlog tabs. Follow [timeline.md](../../timeline.md) for new-plan questions, schedule changes and baseline protection. Follow [task-tracking.md](../../task-tracking.md): record proposed actions in Backlog, promote only confirmed IDs, retain source/output chips and update status from evidence. Use concise descriptions and cell notes for history. Match owners by verified email. Key meetings/milestones use the same grid. Preserve merges and dropdowns. Decisions belong in meeting notes and Meeting Briefs; a legacy decision index may link them. Do not create Work Plan or competing task tables. Verify changed rows and links after writes.
