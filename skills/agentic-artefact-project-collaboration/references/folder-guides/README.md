Optional Workstreams, Sprints, Reporting and detailed risk folders are legacy/opt-in extensions; never scaffold them by default. Their generic templates remain in this skill. New employees read Project/STATUS and their personal identity, then relevant folder guidance and task evidence. No background synchronization is implied.
